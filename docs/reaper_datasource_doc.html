Overview

reaper-datasource is a REAPER extension that reads tabular files and hands the results to Lua, EEL, or Python scripts as ReaScript API functions in the reaper namespace. All calls are synchronous — no job queues, no polling, no external processes.

Supported formats: .xlsx, .xlsm, .xlsb, .xls, .ods, .csv, .tsv. Everything is presented as sheets of rows of string cells; a delimited file is a workbook with a single sheet named after the file. CSV delimiters (comma, semicolon, tab) are sniffed from the first line and a UTF-8 byte-order mark is stripped.

if not reaper.DataSource_Parse then
  reaper.ShowConsoleMsg("reaper-datasource is not installed\n")
  return
end

local ok, result = reaper.DataSource_Parse("/path/to/book.xlsx", "")
if not ok then
  reaper.ShowConsoleMsg("parse failed: " .. result .. "\n")
  return
end
-- result is a JSON string; decode with your JSON library of choice

Conventions

  • Return style. Most functions return a boolean and a string: local ok, result = .... On success the string holds the result (usually JSON); on failure it holds an error message.
  • Result size is unbounded. Results flow through REAPER's buffer-growth mechanism, so multi-megabyte JSON returns work fine from ReaScript.
  • Cells are strings. Empty cells are "". Integral numbers render without a decimal point ("42", not "42.0"); booleans are "TRUE"/"FALSE"; dates are formatted YYYY-MM-DD HH:MM:SS.
  • Rows are absolute. Spreadsheet data is anchored at cell A1, so a row's index is its sheet row number, and the 1-based hidden_rows list aligns with data. Hidden rows are read from .xlsx/.xlsm worksheets; other formats report none.

One-shot parsing

Parse a whole file (or selected sheets) in a single call. Best for bulk imports where the script wants everything at once.

boolean ok, string result = reaper.DataSource_Parse(file_path, options_json)

Parses a tabular file into the workbook JSON shape.

file_pathPath to the file to parse.
options_jsonOptional JSON object. Keys: sheets — array of sheet names to parse (default: all sheets). Pass "" for defaults.

boolean ok, string result = reaper.DataSource_ListSheets(file_path)

Sheet names and visibility without reading cell data: {"sheets":[{"name":"Sheet1","visible":true}]}.

Handle-based querying

Open a source once, then query it incrementally — previews, single cells, row ranges — without materializing the whole file. Sheets load lazily on first access and stay cached on the handle.

local src, err = reaper.DataSource_Open("/path/to/book.xlsx")
if not src then return end
local ok, rows = reaper.DataSource_GetRows(src, "Sheet1", 1, 20)
reaper.DataSource_Close(src)
Handles are opaque and validated on every call — a closed or invalid handle returns (false, message), never a crash. They are not garbage-collected: call DataSource_Close when done.

DataSource src, string error = reaper.DataSource_Open(file_path)

Opens a tabular file for querying. Returns nil and an error message on failure.

boolean closed = reaper.DataSource_Close(src)

Closes an open source and frees its cached sheets. Returns false if the handle was not open.

integer count = reaper.DataSource_CloseAll()

Closes every open source; returns how many were closed. Useful in error handlers and at script shutdown.

boolean ok, string result = reaper.DataSource_GetInfo(src)

File name, file type, and per-sheet name/visibility as JSON, without reading cell data.

boolean ok, string result = reaper.DataSource_GetSheetConfig(src, sheet_name)

One sheet's dimensions and hidden rows — the config object from the workbook shape.

sheet_name"" selects the first sheet.

boolean ok, string result = reaper.DataSource_GetRows(src, sheet_name, start_row, row_count)

A slice of rows as a JSON array of arrays.

sheet_name"" selects the first sheet.
start_row1-based absolute sheet row.
row_count<= 0 means all remaining rows. Rows beyond the sheet yield [].

boolean ok, string value = reaper.DataSource_GetCell(src, sheet_name, row, column)

A single cell's string value (1-based row and column). Cells beyond the sheet's extent read as "", like unset cells in a spreadsheet.

boolean ok, string version = reaper.DataSource_GetVersion()

The extension version, for capability checks.

boolean ok, string path = reaper.DataSource_OpenDocs()

Opens this documentation in the default browser — the bundled file when installed via ReaPack, the project page otherwise — and returns the location opened.

JSON shapes

DataSource_Parse returns a workbook object. The same config vocabulary appears in GetSheetConfig, and GetRows returns bare data slices.

{
  "config": { "file_type": "excel", "file_name": "book.xlsx", "sheets": 2 },
  "sheets": [
    {
      "config": {
        "name": "Sheet1",
        "column_count": 3,
        "row_count": 10,
        "hidden_rows": [4, 7],
        "bold_rows": []
      },
      "data": [["a", "b", "c"], ["", "1", "2.5"]]
    }
  ]
}

file_type is "excel" for spreadsheet formats and "csv" for delimited files. Delimited files always produce exactly one sheet, named after the file, with no hidden rows.
